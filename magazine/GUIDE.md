# 셀러KIM 편집 가이드

주간 매거진 **셀러KIM**을 쓸 때 지킬 것. 2호 피드백(2026-09-15)에서 확정됐다.

---

## 1. 독자가 누구인가

**온라인 셀러**다. 단, **데이터를 잘 보지 못한다.**

- 차트를 해석하거나 표를 비교하며 읽지 않는다.
- 통계 용어(정규화, 상관, 백분위)를 모른다.
- 바쁘다. 끝까지 안 읽는다.

그래서 **"읽고 나면 한두 개가 기억에 남는 글"**이 목표다. 많이 담는 게 아니라 **적게 담고 잘 남기는 것**이 성공이다.

### 모든 코너가 셀러를 겨냥할 필요는 없다

셀러 대상 매거진이지만 **전체를 셀러 조언으로 채우면 읽기 피곤하다.** 코너마다 성격을 나눈다.

| 코너 | 성격 |
|---|---|
| ① 한국엔 아직 없는 트렌드 | **읽을거리** — 문화 차이 이야기로 쓴다 |
| ② 지난주 그 키워드 | **셀러용** — 팔고 안 팔고의 판단 재료 |
| ③ 이번 주 많이 찾은 것 | **읽을거리** — 요즘 뭘 찾나 구경 |
| ④ 이게 뭐죠? | **읽을거리** — 재미 위주 |
| ⑤ 해외 시장 쪽지 | **반반** — 일정은 셀러용, 소식은 구경거리 |
| ⑥ 곧 시즌이 옵니다 | **셀러용** |

읽을거리 코너에서는 "팔아보세요", "진입 적기" 같은 말을 아예 쓰지 않는다. **왜 이런 일이 벌어지는지 설명**하는 데 집중한다.

## 2. 절대 원칙 7가지

### ① 인사이트는 1~2개만

한 호에 다루는 핵심 발견은 **최대 두 개**. 나머지는 "짧은 소식"으로 두세 문장씩만.

> 나쁜 예: 코너 6개에 각각 표와 차트 (창간호)
> 좋은 예: 가을 옷 이야기 하나 + 비어 있는 자리 하나 (2호 재작성본)

### ② 차트는 아주 조금만

**한 호에 1개**가 기본. 많아야 2개. 차트는 본문에서 이미 말한 것을 **눈으로 한 번 더 확인시키는 용도**이지, 차트가 정보를 전달하게 두면 안 된다.

**표는 되도록 쓰지 않는다.** 표에 넣고 싶은 내용은 항목별 문단으로 푼다.

### ③ 어투는 '옆에서 말해주듯 편하게'

가르치거나 지시하지 않는다. **본 것을 전해주는 말투**로 쓴다.

| 쓰지 말 것 | 이렇게 |
|---|---|
| ~하세요 / ~해야 합니다 | ~해 보셔도 좋겠어요 / ~인 것 같아요 |
| 지금이 진입 적기입니다 | 작년 흐름과 비슷하다면 9월 말이 고비로 보입니다 |
| 이 키워드를 잡으십시오 | 이런 자리가 비어 있더라고요 |
| 반드시 확인해야 합니다 | 확인해 보시는 게 좋겠어요 |

**'~습니다'로만 쭉 가면 딱딱해진다.** 기본은 `~습니다`로 두되, 문단마다 한두 번은 `~요`로 풀어준다. 사실을 말할 땐 `~습니다`, 내 생각이나 반응을 말할 땐 `~요`가 자연스럽다.

> 딱딱한 예: "한국에서 비슷한 말을 찾아보니 1,920번이었습니다. 수요가 잘 안 보입니다."
> 고친 예: "그래서 우리나라는 어떤가 싶어 찾아봤는데, 1,920번이더라고요. 미국의 500분의 1 수준입니다."

자주 쓰면 좋은 말끝: **~더라고요, ~같아요, ~예요, ~거든요, ~겠죠, ~로 보입니다, ~인 듯합니다**

쓰면 좋은 연결: "그래서 ~는 어떤가 싶어 찾아봤는데", "생각해보면 당연한 게", "처음엔 저도 ~인 줄 알았어요", "왜 이런가 보니"

1인칭(저/제가)을 숨기지 않는다. 데이터를 넘겨보다 눈에 걸린 것을 전하는 사람이 화자다.

### ④ 쉬운 말로 — 단, 셀러가 매일 쓰는 말은 그대로

"쉬운 말"은 **분석 용어를 풀어 쓰라**는 뜻이지, 셀러 업계 말까지 풀어 쓰라는 뜻이 아니다. 2호 7판 피드백: *"'해외로 파시는 분들께' 같은 표현은 적절하지 않다. '해외셀러', '역직구'가 익숙하다."* 익숙한 말을 굳이 풀어 쓰면 오히려 어색하고, 독자를 초보 취급하는 느낌을 준다.

**그대로 쓰는 말 (셀러 일상어)**: 셀러, 해외셀러, 국내 셀러, 역직구, 소싱, 소싱처, 진입, 판매자, 판매처, 위탁, 마진, 카테고리, 리스팅(아마존 문맥)

| 쓰지 말 것 | 이렇게 |
|---|---|
| 해외로 파시는 분들 / 미국으로 파실 계획 | 해외셀러 / 미국 역직구를 준비 중이라면 |
| 실제로 물건을 파시는 분들 | 실제로 판매 중인 셀러 |
| 물건 떼오는 곳 / 떼올 수 있느냐 | 소싱처 / 소싱이 되느냐 |
| 새로 들어가시는 건 | 새로 진입하는 건 |
| 만드는 곳이 정해진 브랜드 물건 | 제조사가 정해진 브랜드 상품 |
| 파는 곳 562군데 | 판매자 562곳 |
| 카테고리 | 분야 / 종류 (문맥에 따라 그냥 생략) |
| 트래픽 / 노출 | 사람이 들어온다 / 검색에 보인다 |
| 시그널 | 신호 / 조짐 |
| MoM, QoQ | 한 달 전보다, 석 달 전보다 |
| 정규화, 백분위, 상관 | (쓰지 않는다) |
| 검색어를 **치다** / 콕 집어 치다 | ~로 검색하다 / 검색창에 넣다 |
| 검색이 **튀다** / 튀는 | 검색이 부쩍 늘다 / 갑자기 늘다 |
| 검색창에 **찍히다** / 꺼내 들다 | 검색 숫자에 나타나다 / 가장 많이 검색하다 |
| 배송 기간이 **안 나온다** | 행사 전에 도착하기 어렵다 |
| 시차의 **얼굴**, 집의 **표정** | 시차의 모습, 집 안팎 — 비유는 한 호에 한 번이면 충분 |

**내부 용어는 절대 노출하지 않는다** — `v333`, `gg_surge`, `az_pre`, `hit_pct`, `체인 완성`, `국소 스파이크`, `크로스 플랫폼`.

### ⑤ 이미지는 내용과 정확히 맞을 것

**맞는 사진이 없으면 사진을 넣지 않는다.** 분위기용 스톡 사진은 오히려 신뢰를 깎는다.

2호 초안에서 실제로 저지른 실수:
- 낚시 미끼 이야기에 **피규어 사진**을 붙임
- 가을 패션 이야기에 **한복 사진**을 붙임
- 김치 이야기에 **길거리 음식 사진**을 붙임

가장 안전한 건 **아이템스카우트 API가 주는 실제 상품 이미지**다. 그 상품 자체이므로 어긋날 수 없다.

**2호 5판에서 또 저지른 실수 (2026-09-15 피드백: "의미없거나 관계없는 이미지나 일러스트는 넣지 마")**
- 코너 머리마다 **장식용 일러스트** 6장 → 전부 삭제. 내용을 전달하지 않는 그림은 지면 낭비다.
- 삼계탕사발면에 **일본 컵라면 매대**, 귀멸의칼날에 **팝마트 매장**, 워킹패드에 **헬스장 러닝머신** → 비슷한 것은 관계없는 것이다.

**4호에서 또 저지른 실수 (2026-09-21 피드백: "쓰이누 사진은 라부부야")**
- 소파에 앉은 인형 사진을 **'치이카와 앉은누이'** 라고 캡션에 단정했다. 실제로는 **라부부**(팝마트)였다.
- 3호에서는 염소·나무늘보 인형이 쌓인 선반 사진에 같은 캡션을 붙였다. 역시 다른 상품이었다.
- **저작권 캐릭터는 스톡에 없고 생성해서도 안 된다.** 치이카와·라부부 같은 IP 는 사진으로 보여 줄 방법이 없다.
- 그래서 규칙을 하나 더 둔다 — **캡션에서 상품을 단정하지 않는다.** 그 상품의 실제 사진(아이템스카우트 API)이
  아니면 "사진은 이해를 돕기 위한 것으로, 해당 상품은 아닙니다" 를 붙이거나, 아예 그 상품을 가리키지 않는
  장면(매대가 채워지는 모습 등)으로 바꾼다.
- alt 만 보고 넣지 말고 **Read 로 눈으로 확인한 뒤, 캡션이 사진보다 더 많이 주장하지 않는지** 한 번 더 본다.

**실사, 그리고 톤앤매너 통일**
- 사진은 **실사**만. 일러스트·SVG·아이콘은 쓰지 않는다.
- 스톡 사진은 **자연광·따뜻한 중간톤·생활 장면**으로 고른다. 스튜디오 흰 배경 모델컷, 어두운 무드컷은 섞이면 티가 난다.
- 생활 사진에는 `figure.ph`(`filter:saturate(.88) contrast(1.03)`)를 일괄 적용해 톤을 맞춘다. 상품 사진(`.card img`, 흰 배경)에는 적용하지 않는다.
- 비율도 통일: 단독 사진 3:2, 나란히 두 장은 1:1, 표지 4:3.
- **실물 사진을 못 구하면 실사풍으로 생성한다** (아래 절차). 단, 꼬리말에 "AI로 생성한 연출 이미지"라고 반드시 적는다. 2호 6판: 워킹패드·여드름 패치 2장.

### ⑥ 사진은 많이 — 매거진이다

글만 이어지면 매거진이 아니라 보고서다. 다만 **장수보다 크기와 적합성**이 먼저다. 기사마다 사진 1장 이상, 전체 15~20장. 2호 6판은 19장(장식 일러스트 6장을 빼고도 그렇다).

배치 규칙:
- 맨 위에 **와이드 히어로 사진** 1장 (그 호의 계절·분위기)
- 표지는 커버스토리 사진 위에 제목을 얹는다(`.cover`)
- 소제목마다 사진 1~2장. 대비되는 두 장이 있으면 `.pair`로 나란히
- 상품 항목은 `.card` — **230px 정사각 이미지 + 오른쪽 글**
- 캡션은 사진 설명이 아니라 **한 줄 거리의 내용**을 담는다. "가을 장식" ❌ → "바구니에 호박을 담아두는 것도 어엿한 장식입니다" ✅

> ⛔ **작은 썸네일 금지.** 64px짜리 아이콘 크기 이미지는 넣느니 안 넣는 게 낫다.
> 넣을 거면 **내용이 보이는 크기**로 넣는다(`.card` 230px 이상, `figure`는 본문 폭 전체).

**사진 구하는 법 (브라우저 MCP 없이도 됨)**
```
WebFetch https://unsplash.com/s/photos/<검색어>   → photo ID + alt 목록을 받는다
curl -sL -A "Mozilla/5.0" -o img/un_NAME.jpg \
  "https://images.unsplash.com/photo-XXXX?w=1200&q=72&auto=format&fit=crop"
sips -Z 1000 -s formatOptions 58 img/un_NAME.jpg --out img/un_NAME.jpg   # base64 내장 대비 압축
```
- `source.unsplash.com`은 폐기됨(503). 쓰지 않는다.
- 내려받은 뒤 **반드시 Read 툴로 눈으로 확인**한다. alt만 믿으면 어긋난다(alt "squid lure"가 일반 루어인 경우 등).
- 검색어는 구체적으로. `fishing` ❌ → `squid fishing lure jig` ✅
- 전체 img 폴더가 3~4MB를 넘으면 base64 내장 시 아티팩트가 무거워진다. `sips -Z 1000`으로 줄인다.

**실사 이미지 생성 (Gemini 2.5 Flash Image)** — Unsplash에 없는 장면에만

스톡에 없는 장면(책상 밑 워킹패드, 볼에 붙인 여드름 패치)은 실사풍으로 생성한다. 스크립트는 `magazine/genimg.py` 참고. **장식용 일러스트 생성은 하지 않는다.**

```bash
K=$(grep -m1 '^GEMINI_API_KEY=' worker/.env | cut -d= -f2-)
curl -s -X POST "https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash-image:generateContent?key=$K" \
  -H 'Content-Type: application/json' --data-binary @req.json -o out.json
# out.json → candidates[0].content.parts[*].inlineData.data (base64 PNG, 1024x1024)
```

- **python `urllib`은 SSL 인증서 오류가 난다. 반드시 `curl`로 호출한다.**
- 결과는 1024×1024 PNG 1.5~1.9MB. 크롭·압축 후 100KB 안팎이 된다.
- **스타일 문구를 모든 프롬프트에 똑같이 붙여야** 스톡 사진과 톤이 맞는다:
  > Photorealistic editorial lifestyle photograph, shot on a 35mm lens, soft natural window light, warm neutral color grade, shallow depth of field, candid and unposed, muted tones, no text, no logos, no brand names, no watermark. Horizontal 3:2 composition.
- 크롭은 `sips -s format jpeg -c 683 1024` (3:2), 압축 `-Z 1100 -s formatOptions 70`.
- **"no text, no letters" 를 반드시 넣는다.** 안 넣으면 읽을 수 없는 가짜 글자가 들어간다.
- 구도는 가운데로 모인다. 정사각에서 4:3 센터 크롭해도 잘리지 않는다.
- SVG는 쓰지 않는다(확정 사항).

### ⑦ 핵심 키워드엔 형광펜

독자는 끝까지 안 읽는다. **훑어봐도 핵심이 눈에 걸리게** 형광펜을 긋는다.

```html
<span class="hl">핵심</span>        <!-- 노랑: 발견·기회 -->
<span class="hl r">주의할 숫자</span>  <!-- 붉은 기: 경고·포화 -->
```

- **코너당 2~3군데.** 많이 칠하면 형광펜 의미가 없어진다(3호 기준 전체 12군데).
- 긋는 대상: 해외 원어 키워드(`fall decor`), 대비되는 숫자쌍, 풀이의 결론("미끼 색깔 이름")
- **붉은 형광펜(`.r`)은 경고에만** — 포화 상태, 과잉 등록 상품 수
- 제목(h2/h3)에는 긋지 않는다. 본문 안에서만.

## 3. 고정 코너 (2026-09-15 확정)

매주 이 순서로 쓴다. 각 코너는 짧은 글 하나씩이라 코너가 늘어도 읽는 부담은 적다.

### ① 한국엔 아직 없는 트렌드 — **첫 코너**

해외에서는 잘 팔리는데 한국에는 아직 안 온 것 2~3개. **이 매거진에서만 얻을 수 있는 정보**라 맨 앞에 둔다.

- 찾는 법: 아마존 US·JP 급등 키워드(`amazon_brief.py`) → 한글 대응어로 옮김 → 아이템스카우트로 한국 검색량 확인
- 이번 주 예: `fall decor`(미국 100만 / 한국 380), `lash clusters`(미국 110만 / 한국 40)
- **한글 대응어는 동의어를 3~4개 시도해 검색량이 가장 큰 것을 고른다.** 하나만 보면 틀린다(`속눈썹클러스터` 0 vs `속눈썹연장세트` 40)
- **단정하지 않는다.** 한글 표현을 못 찾아 "없다"고 쓸 위험이 있으므로 *"제가 찾아본 말로는 아직 안 보입니다"* 정도로 여지를 둔다

### ② 지난주 그 키워드, 지금은?

저번 호에 다룬 키워드가 그 뒤 어떻게 됐는지 3~4개 추적.

- 매거진이 맞았는지 틀렸는지 스스로 보여주는 코너다. **틀렸으면 틀렸다고 쓴다.**
- 데이터: `data/cand_naver.csv`에 29주치 주간 검색량이 쌓여 있음
- 예: "피자설기는 한 주 만에 7.4만 → 12.2만으로 늘었습니다" / "왁뿌볼은 계속 내려가는 중입니다"

### ③ 이번 주 많이 찾은 것 — **정보 전달 전용**

국내에서 검색이 크게 늘어난 것들.

> ⚠️ **상품 발굴 코너가 아니다.** 급등 키워드는 대부분 **브랜드 상품**(삼계탕사발면=농심, 노스페이스 벤투스, 박미희김치)이라 검색이 비어 있어도 물건을 못 떼오면 의미가 없다. "여기 들어가세요"로 쓰면 독자를 헛걸음시킨다.
>
> **"이런 게 뜨고 있습니다"까지만 쓴다.** 판단은 독자 몫으로 남긴다.

### ④ 이게 뭐죠?

처음 보는 말 3~4개 풀이. 매주 신규 키워드가 50개 넘게 나오니 소재는 늘 충분하다.

- 예: 익수황진환, 에기(오징어 낚시 미끼), 톱밥꽃게, 피자설기
- 셀러 조언이 아니라 **읽는 재미**로 쓴다. "저도 처음엔 과일인 줄 알았어요" 같은 반응을 숨기지 않는다

### ⑤ 해외 시장 쪽지

**해외셀러(역직구)용**. ①번과 방향이 반대다(①은 국내 판매, ⑤는 역직구).

- 예: 미국 할로윈 시즌, 일본 신작 애니 굿즈
- 독자 호칭은 **해외셀러**, 방향은 **역직구**. '해외로 파시는 분' 같은 풀어쓰기는 하지 않는다

### ⑥ 곧 시즌이 옵니다 *(격주)*

4~8주 앞 시즌 예고. 매주 쓰면 반복되므로 격주.

## 3-1. 한 호의 구조 — 기사여야 한다 (2026-09-15 재확정)

2호 5판까지의 피드백: *"왜 기획이나 기사 느낌이 없을까"*. 원인은 **코너 = 항목 나열**이었기 때문이다. 숫자를 순서대로 읽어주는 건 보고서지 잡지가 아니다.

**한 호에는 주제가 있고, 각 코너는 기사다.**

```
제호            셀러KIM · 제N호 · 날짜
표지            커버스토리 사진 위에 제목 + 한 줄 (사진은 커버스토리 주제 그대로)
목차            코너별 제목 + 한 줄 요약
편집자의 말     이번 호를 관통하는 주제 한 단어와 그 이유 (3~4문장)
커버스토리      ① 한국엔 아직 없는 트렌드 — 가장 긴 기사 (2,000~2,500자)
기사            ③ 이번 주 많이 찾은 것 — 그 주의 한 가지 발견을 기사로, 나머지는 '급등 목록' 박스
기사            ④ 이게 뭐죠? — 가장 재미있는 하나를 추적기로, 나머지 둘은 카드
팔로업          ② 그 후 — 카드 4개, 각각 마지막 줄에 판단 한 줄
통신            ⑤ 해외 시장 쪽지 — 도시 datelines (뉴욕 — / 도쿄 —)
달력            ⑥ 앞으로 여덟 주
숫자 보는 법 / 꼬리말
```

### 기사의 조건

| 요소 | 나쁜 예 (2호 5판) | 좋은 예 (2호 6판) |
|---|---|---|
| **제목** | 코너 이름을 그대로 ("한국엔 아직 없는 트렌드") | 주장이나 장면 ("바다 건너 9월", "덜 익은 망고는 과일이 아니었다") |
| **부제(deck)** | 없음 | 기사가 무엇을 따라가는지 2~3문장 |
| **리드** | 숫자부터 ("미국에서 X를 100만 번 찾습니다") | 장면부터 ("미국에서는 9월 첫째 주가 되면 현관에 호박이 놓입니다") |
| **전개** | 항목 나열 | 의문 → 추적 → 발견. "여기까지는 예상 안에 있었습니다. 그런데 한 숫자가 걸렸습니다." |
| **맺음** | 없음 | 그 호의 주제로 되돌아오는 한 문장 |
| **인용(pull quote)** | 없음 | 기사당 1개. 본문에서 가장 강한 문장을 큰 글씨로 다시 |
| **주제 연결** | 코너끼리 무관 | 편집자의 말에서 꺼낸 단어(2호: '시차')가 각 기사 맺음에 다시 나옴 |

- 코너 이름은 **kicker**(작은 글씨)로만 남긴다. `커버스토리 · 한국엔 아직 없는 트렌드`
- 첫 문단은 `.lead` — 두문자 크게(drop cap). 잡지 신호다.
- 어투는 §2-③ 그대로. 기사 구조를 갖추면서 말투까지 딱딱해지면 안 된다.

분량은 **본문 6,000~8,000자** (2호 6판: 7,356자).

## 3-2. 발행 전 문장 점검 (2호 8→9판에서 55문장 수정)

기사 구조를 갖춘 뒤에도 문장 단위로 어색한 것이 많았다. 발행 전에 **본문 텍스트만 뽑아서 처음부터 끝까지 읽는다** (`build` 후 태그 제거한 텍스트). 자주 걸리는 패턴:

| 패턴 | 나쁜 예 | 고친 예 |
|---|---|---|
| 뜻이 흐릿한 문학적 마무리 | 그 사이에 무엇이 있는지 따라가 봤습니다 | 왜 이런 차이가 나는지 살펴봤습니다 |
| 사물을 의인화 | 하나의 단어가 계속 따라왔습니다 / 한 숫자가 걸렸습니다 | 계속 떠오른 단어가 있습니다 / 이상한 숫자가 하나 있었습니다 |
| '물건' 남발 | 새로울 게 없는 물건 / 오래 가는 물건 | 상품 |
| '사람' 으로 수치 표현 | 파는 쪽이 사는 쪽보다 500배 | 검색 수보다 상품 수가 500배 |
| '우리/우리나라' | 우리에게 없다 / 우리는 의상보다 | 한국에 없다 / 한국은 의상보다 |
| 검색을 동작으로 | 검색창도 같이 바뀌었습니다 / 찾아봐도 | 검색어도 함께 바뀌었습니다 / 검색해도 |
| '것' 나열 | 아무것도 안 건너온 것, 상품만 건너온 것 | ~ 단계, ~ 단계 |
| 구어체 어미 | ~겠지요 / ~니까요(연속) | ~입니다 |

원칙: **한 문장을 소리 내 읽어 숨이 걸리면 고친다.** 비유는 한 호에 두세 개면 충분하다.

## 4. 매 호 반드시 넣을 것

- **"물건을 떼올 수 있는가"** — 검색이 많아도 브랜드 상품이면 소싱이 전부다. 이 단서를 빼면 독자를 헛걸음시킨다.
- **함정 한 줄** — 라이선스 필요 품목, 이미 포화된 것, 규제 품목. 별도 코너가 아니라 **해당 문단 안에 한 줄로** 넣는다.
- **급등률의 착시** — "몇 배 올랐다"는 원래 0이던 게 조금 오른 것일 수 있다. 절대 검색 수와 함께 보라고 매번 알려준다.

## 6. 숫자를 쓰는 법

- **검색 수는 절대값으로** 쓴다. "한 달 검색 140,300번"
- **등록 상품 수와 나란히** 놓는다. 이 대비가 매거진의 전부다.
- 비율·배수는 **말로 풀어서** 쓴다. "검색 한 번에 상품 179개가 기다리고 있는 셈입니다"
- 소수점, 퍼센트 기호, 과학적 표기는 쓰지 않는다.
